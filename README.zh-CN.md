# GUAN · 国际分享版

[直接开始游戏](https://jwxxc.github.io/guan-international/) · [English](README.md)

这是独立制作的网页分享特别版，默认英文。首页或设置中可切换为中文，选择会记住；对局中切换语言不会重新发牌，也不会改变当前选牌和进度。原有常规版不受影响。

包含经典升级、单副练习、手牌整理、三种手牌布局、战绩、分析档案、回放和七首背景音乐。网页可用四档电脑：休闲、均衡、均衡 Plus、均衡 Pro；实验策略名称不代表已经证实的强度顺序。

建议使用电脑浏览器，窗口宽度至少 1024 像素。无需账号或安装。牌局在浏览器本地运行；存档留在当前浏览器、当前网址，不会自动跨设备同步，清除网站数据会删除这些记录。

DanLM、DanLM 提示和新观战研习需要本机模型服务，GitHub 网页不支持，菜单中会明确禁用。私人联机和自动学习也不由这个静态网站提供。分享网址后，每个人玩的是自己的本地电脑局。

单击或快速划过选牌，双击选同点数；按住片刻再拖动可移牌。松开拖动不会出牌，须点“出牌”确认。完整中英文规则见游戏内“玩法说明”。

源码运行需要 Node.js 22.12+ 和 pnpm 11.19.0：

```sh
pnpm install --frozen-lockfile
pnpm dev
```

测试：`pnpm test`。浏览器测试：先运行 `pnpm exec playwright install chromium webkit`，再运行 `pnpm test:e2e`。构建：`pnpm build`。

此仓库不含常规版 App、个人对局、研究导出或私有 DanLM 权重。
