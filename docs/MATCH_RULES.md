# GUAN 连续升级规则 · guan-match-v1

历史兼容规则：新开经典升级使用 [RULES_CLASSIC_V1.md](RULES_CLASSIC_V1.md) 的 `guan-classic-house-v1`。下文保留用于恢复与回放旧版日志，不再作为新场规则。

本规则在原单副牌型 guan-practice-v1 之上增加连续升级和贡还牌。选定3/2/1、必须过A的玩法；不宣称完整复刻所有地方玩法或赛事标准。

两队各从2独立记录级数。头游队搭档二/三/末游，分别升3/2/1；另一队保持。下一副全桌共同使用上一副头游队升级后的级数。升到A封顶，必须实际打一副A级并拿头游且同伴不是末游才通关；若两队都在A，本副打A时任一队达到该名次条件均可通关。打A失败保留A，不采用三次失败退2变体。初副随机先手。单副练习保留原来可选级牌、独立发牌的模式。

第二副起单贡：上副末游向头游贡一张最大牌（按新一副的单张强度，排除红心级牌），即使两人是队友也照常；受贡者还一张小牌，末游先出。双下则两人各贡一张：较大给头游，较小给二游；同点按顺时针进贡（当前座位逆时针编号0→1→2→3，因此顺时针相邻受贡者为 donor-1 mod4），对应还牌；给头游进贡者先出。单贡者拥有两张大王，或双下两人合计持有两张大王则抗贡，不交换，头游先出。

还贡优先允许本副单张强度不高于10的牌，排除王、级牌与逢人配；如没有则允许本副单张强度最小的非逢人配牌。若极端情况下只有逢人配才有牌，则取实体最小者作为保底（完整27张正常发牌不会出现）。这段对级牌的还贡排除与保底属于明确的软件落地约定。进贡同点实体允许持有者选花色，返牌由受贡者从合法候选选择；电脑仅看自己的交换观察，不读取其他人手牌。

交换顺序按阶段一次性结算：双方先各选贡牌，再统一转移，随后各自从受贡后的手牌选还牌。未完成选择的另一家贡牌不会因UI选择顺序改变规则。最终每家仍为27张、108实体无重复；所有交换动作带手牌ID和版本，纳入存档及回放。

资料：
- [中国地质大学（北京）规则](https://xgh.cugb.edu.cn/c/2022-09-22/761288.shtml)：3/2/1、贡还与过A。
- [燕山大学规则](https://iee.ysu.edu.cn/info/1337/24765.htm)：还牌上限与无小牌时还最小。
- [南京信息工程大学规则](https://webs.nuist.edu.cn/_s66/2023/1213/c2331a234305/page.psp)：等点顺时针贡还；不采用该场赛事的到A即止终局。
- [宿迁协会2019征求稿](https://www.ttbz.org.cn/upload/file/20191223/6371270213033087899544901.pdf)：两队进度与本副共用级牌的交叉定义，仅作对照。
